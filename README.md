# Budss

Responsive landing page built with semantic HTML, modular CSS and vanilla JavaScript.

## Highlights

- Responsive layout for desktop and mobile
- Reusable UI sections and interactions
- Optimized static assets
- Netlify-ready deployment

## Tech stack

HTML5 · CSS3 · JavaScript · Netlify

## Run locally

Open `index.html` in a browser or serve the project with a static HTTP server.

## Structure

- `css/`
- `img/`
- `js/`
- `index.html`
- `netlify.toml`
